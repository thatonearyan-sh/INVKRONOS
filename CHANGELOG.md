# Changelog

All notable changes to the **INVKRONOS** ecosystem are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [5.2.0] - 2026-09-08
### Added
- **Flagship 24-Bit TUI**: Authentic curses terminal interface with green matrix rain and reactive header telemetry.
- **TON Blockchain Watcher**: Real-time decentralized transaction settlement via Toncenter RPC and memoized KRN tokens.
- **Zero-Presence RAM Daemon**: Dynamic payload stream decryption executing strictly in volatile RAM without disk footprints.
- **Telegram Admin Push Service**: Real-time payment notifications with 1-click inline approval and instant license dispatch.
- **Full Architecture Blueprint**: Comprehensive dual-column operator reference and deployment matrix.

### Changed
- Refactored MTProto RPC query batching to enforce zero online presence markers.
- Accelerated voice note transcription pipeline with chunked in-memory WAV buffers.
- Hardened serverless ASGI middleware against brute-force license verification attempts.

### Security
- Added Ed25519 signature verification across all incoming webhook events.
- Hardened device HWID binding ceiling enforcing atomic 3-device limit per license.
